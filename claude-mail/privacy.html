Privacy policy

Last updated 9 October 2026.

Claude Mail is a personal tool. The only Google account it accesses is the owner's own.

What it accesses

With the owner's permission, it uses the Gmail API with the read-only scope (gmail.readonly) to search the owner's email and download attachments.

How data is used and stored

Email content and attachments are downloaded only to the owner's own computer, for his own use. Nothing is sold, shared with third parties, used for advertising, or stored on any server run by this app. The access token is kept only on the owner's computer.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions.
